# File headers and exceptions

Plugin-owned Ruby, ERB, CSS, Markdown, YAML, shell, Docker and nginx configuration
files carry a complete repository-relative path and GPL-2.0-or-later SPDX header.
Comment syntax is adapted to each format. The root `LICENSE` remains the verbatim
GNU General Public License text; it is not modified to insert a source header.

| File | Metadata handling |
| --- | --- |
| `redmine_mirror/config/mirror.example.json` | Plugin configuration example, GPL-2.0-or-later. Standard JSON forbids comments, so this document records its header metadata. |
| `redmine_mirror/test/environment/fixtures/mirror-note.txt` | Plugin-owned attachment fixture, GPL-2.0-or-later. Its bytes are intentionally preserved for import tests. |
| `redmine_mirror/LICENSE` | Verbatim GNU GPL version 2 license text; source files permit version 2 or later. |
| `redmine_mirror/doc/images/*.png`, `redmine_mirror/doc/screenshots/**/*.png` | Plugin-owned screenshots, GPL-2.0-or-later, generated by `test/documentation/run.sh` and `test/documentation/migration_run.sh`; regenerate rather than edit them. |
| `redmine_mirror/assets/images/synchronisation-des-donnees*.png` | Binary third-party artwork; see [artwork credits](../assets/images/CREDITS.md). |

See [development conventions](DEVELOPMENT.md) when adding files.
